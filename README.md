# AIN Cloud

Облачное хранилище 4K-медиа для ain.kz: загрузка больших файлов частями напрямую в хранилище, неизменяемые оригиналы с проверкой SHA-256, просмотр 4K-видео в браузере (HLS), фото и RAW, публичные ссылки, админ-панель и маскот Барыс.

## Что уже работает

## Архитектура

```
Браузер (Next.js) ──/api──▶ API (NestJS) ──▶ PostgreSQL
     │                          │  └────────▶ Redis (BullMQ)
     └── части файла, сегменты ─┼──────────▶ MinIO / S3 (приватные бакеты, SSE)
         по подписанным ссылкам │                  ▲
                                ▼                  │
                     Воркер (FFmpeg, libvips, ExifTool, LibRaw, ClamAV) — без интернета
```

| Каталог | Что внутри |
|---|---|
| `apps/web` | Next.js 16, React 19, Tailwind 4 — интерфейс, загрузчик, плеер, маскот |
| `apps/api` | NestJS 11 — авторизация, папки, материалы, загрузки, ссылки, админка; OpenAPI на `/api/docs` |
| `apps/worker` | Проверка (SHA-256, тип, ClamAV), превью, HLS, обслуживание (просроченные загрузки, корзина) |
| `packages/db` | Схема Prisma, миграции, начальные данные (тарифы, настройки), назначение сотрудников |
| `mascot` | Исходники прототипа Барыса (GLB поз и процедурная модель) |
| `tests/e2e` | Сквозные тесты API и браузерный сценарий |

## Запуск локально

Нужны Docker Desktop и Node.js 22+.

```bash
npm install
npm run env:init                 # .env со случайными секретами
docker compose up -d             # Postgres, Redis, MinIO, ClamAV, Mailpit, воркер
npm run db:deploy && npm run db:seed
npm run build -w @ain/api && npm run start -w @ain/api      # API на :4000
npm run dev:web                  # интерфейс на http://localhost:3000
```

Всё в контейнерах: `docker compose --profile app up -d --build` (интерфейс на :3000).

Порты опубликованы только на 127.0.0.1 и не пересекаются со стандартными: Postgres 55432, Redis 56379, MinIO 59000 (консоль 59001), Mailpit 58025 (письма с кодами подтверждения видны здесь).

Демо-ролик для главной: `npm run demo:seed` — служебный аккаунт demo@ain.kz загрузит `tests/fixtures/generated/ain-demo-4k.mp4` и опубликует ссылку «только просмотр». Для продакшна замените ролик настоящим: `npm run demo:seed -- путь/к/ролику.mp4 --force`.

Сделать пользователя администратором: `npm run staff -w @ain/db -- user@example.com ADMIN`. При первом входе в админ-панель он включит 2FA.

ClamAV при первом старте скачивает базы несколько минут — до этого загруженные файлы получают «Ограничен» с причиной «антивирус недоступен» (так и требует ТЗ §10.1). Перепроверить их можно в админ-панели.

## Веб-интерфейс на Vercel

Импортируйте `tutto-passa6767/ain-cloud` в [Vercel](https://vercel.com/new) и выберите **Root Directory: `apps/web`**, **Framework: Next.js**, **Node.js: 24.x**. Оставьте включённым **Include source files outside of the Root Directory**. Установка зависимостей и сборка заданы в `apps/web/vercel.json`; Output Directory оставьте по умолчанию. Vercel собирает только веб-интерфейс, используя корневой `package-lock.json` монорепозитория.

Без отдельного API доступны главная и публичные страницы. Регистрация, медиатека, загрузка и обработка файлов требуют NestJS API, PostgreSQL, Redis, S3-хранилища, почты и воркера на отдельном сервере.

После запуска API добавьте в Vercel переменную `API_INTERNAL_URL=https://api.example.com` (без `/api`) и выполните Redeploy: адрес прокси фиксируется при сборке. На сервере API задайте `APP_URL=https://<имя-проекта>.vercel.app`, `COOKIE_SECURE=true` и публичный HTTPS-адрес `S3_PUBLIC_ENDPOINT`; разрешите этот адрес приложения в CORS хранилища. Корневой `.env` с локальными секретами в Vercel не импортируется.

[Бесплатный тариф Hobby](https://vercel.com/docs/plans/hobby) предназначен для личного некоммерческого использования. Настройки монорепозитория описаны в [документации Vercel](https://vercel.com/docs/monorepos).

## Тесты

```bash
sh tests/fixtures/make-fixtures.sh   # 4K-ролик 12 с, фото 6000×4000 с EXIF и GPS, подмена типа
npm run test:e2e                     # API: основной сценарий, безопасность, квоты, возобновление, ссылки, админка
node --test tests/e2e/ui-main-scenario.test.mjs tests/e2e/ui-mascot-drag.test.mjs tests/e2e/ui-features.test.mjs   # браузер (Edge/Chrome, нужен запущенный интерфейс)
```

Браузерный тест проходит регистрацию, создание папки, загрузку настоящего 4K-файла, проверку, воспроизведение в плеере и сверяет SHA-256 скачанного оригинала с исходным.

## Решения, которые стоит согласовать с заказчиком

- **Антивирус и большие файлы.** ClamAV не проверяет файлы больше 2 ГБ, поэтому большие видео получают «Ограничен». Владелец может скачать такой файл после явного подтверждения, гостю по ссылке он не выдаётся. Если нужна другая политика (например, проверка структуры для медиа), её легко переключить в `apps/worker/src/verify.ts`.
- **Кодек версий для просмотра.** По умолчанию H.264 — работает во всех браузерах. `VIDEO_CODEC=hevc` уменьшает объём, `VIDEO_ENCODER=h264_nvenc` / `hevc_nvenc` включает GPU (ТЗ §7.4).
- **Отзыв ссылок.** Новые запросы закрываются сразу; уже выданные адреса сегментов действуют до 2 часов для гостя и 6 часов для владельца, адрес скачивания — 15 минут (ТЗ §9 допускает).
- **Cache Components Next.js выключены:** рабочая часть полностью клиентская (данные через SWR после проверки сессии).
